## Q7 
对照 `src/main/legacy_patrol.py` 中各函数 docstring 的契约，共定位并修复 6 处缺陷。

### Bug 1：单位换算缺失 
- 错在哪：`segment_length_cm` 返回值单位是厘米，原代码把厘米直接累加后当作"米"返回，结果放大 100 倍（7 格的路线被报成 700 米）。
先读函数 docstring 确认返回单位为"米"，再追数据源发现累加的是厘米，单位不一致即问题所在。

### Bug 2：基线为 None 时崩溃
- 错在哪：契约要求"没有正样本时漂移为 0"，但原代码在 `first_positive` 返回 None 后直接执行 `s - baseline`，抛出 TypeError。
按契约构造合法输入（全负样本、空列表）触发异常，从报错反推到缺少 None 判断。
`baseline is None` 时提前返回 0 就能解决

### Bug 3：边界 off-by-one 
- 错在哪：契约是"统计 id **不超过** max_id 的事件"，原代码写成 `e["id"] < max_id`，导致 id 恰好等于 max_id 的事件被漏掉。
边界加个等于就好

### Bug 4：可变默认参数 
- 错在哪：`history=[]` 作为默认参数只在函数定义时创建一次，不传 history 时所有调用共享同一个列表，违背"每次从空历史开始"的契约。
默认值改为 None，函数内部在 history 为 None 时新建空列表。

### Bug 5 and 6 ：终止条件写反 and 循环变量不自增
两处同时修：加`round_ += 1` ，条件改为`stamina <= 20`
